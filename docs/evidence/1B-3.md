## Claims

1. **Pure-Go WebAuthn Manager**:
   - Built in [`hub/pkg/responseauth/webauthn.go`](file:///srv/workspaces/projects/ominull/hub/pkg/responseauth/webauthn.go) without external CGO or third-party dependencies.
   - Generates random 32-byte cryptographic challenges with 5-minute TTL eviction.
   - Implements full clientDataJSON parsing and authenticatorData unpacking.
2. **Cryptographic Algorithm Support**:
   - ES256: ECDSA P-256 with SHA-256 (supports both ASN.1 DER and IEEE P1363 raw signature formats).
   - Ed25519: Pure Ed25519 signatures.
   - RS256: RSA PKCS#1 v1.5 with SHA-256.
3. **Security Invariants Enforced**:
   - **Trusted Origin:** Origin header in `clientDataJSON` verified against allowed origins (`https://ominull.example.invalid:8443`, etc.); phishing/attacker origins rejected with `ErrWebAuthnOriginMismatch`.
   - **RP ID Hash:** Authenticator data RP ID hash verified; mismatches rejected with `ErrWebAuthnRPIDMismatch`.
   - **User Presence:** Flag bit 0 (UP) required on every assertion; missing presence rejected with `ErrWebAuthnUserNotPresent`.
   - **Anti-Cloning:** Strictly incrementing sign counter required; non-incrementing counters rejected with `ErrWebAuthnCloned`.
   - **Honest Labeling:** Authenticators enrolled with label `SecurityLabelWebAuthn` (`Phishing-Resistant (FIDO2 / WebAuthn Hardware Bound)`).
4. **Unix Domain Socket Endpoints**:
   - `/v1/auth/webauthn/register/options`: Provides options for `navigator.credentials.create()`.
   - `/v1/auth/webauthn/register/verify`: Verifies attestation and creates authenticator record in SQLite.
   - `/v1/auth/webauthn/login/options`: Provides options for `navigator.credentials.get()`.
   - `/v1/auth/webauthn/login/verify`: Verifies assertion signature and issues an 8-hour browser-bound response session.
5. **Testing & Deployment**:
   - Verified locally with Go race detector (`go test -v -race ./pkg/responseauth/...`).
   - Verified clean Debian package lifecycle build.
   - Deployed to LXC 150; verified creation options generation and zero telemetry disruption.
