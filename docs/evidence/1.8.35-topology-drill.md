# v1.8.35 topology drill-down evidence

Approved change: icon-led devices, logical boundaries, in-graph exploration,
no inspector sidebar, and pointer-centered wheel zoom. Existing Cytoscape and
worker dependencies remain sufficient; no additional dependency was required.

## Behavioral checks

Failing-first model tests cover reporter ownership, residual traffic totals,
neighbor context, full-path process selection, missing hosts, incoming domain
attribution, peer selection, omitted counts, and valid parent references. Worker
regression checks contextual lanes and fixed positions. Saved-state validation
rejects invalid scope kinds, missing IDs, malformed trails and nested trails.

Preview used a captured workspace containing 785 nodes, 813 directed host pairs
and 11,637 relation rows. Busy-host scene projection averaged 32.4 ms over ten
runs; initial scene had 18 nodes and 12 links, with 3,808 additional links disclosed.
This measures projection only, not browser rendering or all possible workloads.

Observed in the managed isolated browser:

- Native double-click opened a network and then a host with five process nodes.
- Host scene showed directed process/destination links and a reporting-host
  boundary. No right-hand inspector existed.
- Back restored every recorded position with zero drift, plus zoom and pins.
- Saved-view UI create and reload retained scope, navigation trail, positions and
  pins. Temporary verification view was deleted.
- Dispatched DOM wheel events changed zoom without changing scope. Pointer drift
  was below 0.03 px. The automation mouse-wheel helper targeted the browser origin
  despite a preceding move; that helper does not establish physical-wheel proof.
- Keyboard Enter drilled into a List item. Back restored viewport and positions.
- Hover contents and keyboard focus survived a real five-second poll replacement;
  Escape dismissal persisted through the following poll.

Repeat browser checks using `scripts/verify-topology-drill.js` and
`scripts/verify-topology-hover.js` through the managed browser eval command.
The drill script tests DOM wheel handling; it does not simulate trusted hardware.

gofmt, vet and native build passed. Version check passed. Hygiene grep returned

Production release verification is recorded below after canonical deployment.

Production v1.8.34 loaded the new graph with 1,093 addresses, 18 groups and
10 aggregate links. Both browser regression scripts passed on the live route.

shape. Disabling background-image clipping preserves full glyphs while retaining
the selection halo; verified visually before preparing v1.8.35. No topology data
or identity behavior changed in that follow-up.

restored positions with zero drift. The temporary view was deleted. At 1024 × 800,
the graph and controls stayed within the viewport; fitting the busy host scene
reduced labels to about 9 px, so wheel zoom remains useful for close inspection.
