## Claims

1. **Strict Program Allowlist (`agent/include/terminal_windows.h`)**:
   - Only `cmd.exe`, `powershell.exe`, and `pwsh.exe` (PowerShell Core, when installed) are permitted.
   - `Terminal_IsAllowedProgramWindows` resolves canonical system paths (`%SystemRoot%\System32\cmd.exe`, `%SystemRoot%\System32\WindowsPowerShell\v1.0\powershell.exe`, and `C:\Program Files\PowerShell\7\pwsh.exe`) and verifies file presence via `GetFileAttributesA`.
   - Rejects arbitrary executables (`calc.exe`, `notepad.exe`), arguments (`cmd.exe /c ...`, `powershell.exe -Command ...`), relative paths (`..\cmd.exe`), and injection characters (spaces, semicolons, ampersands, pipes).
2. **ConPTY Pseudoconsole Subsystem & Build Baseline**:
   - Headers and build flags define `_WIN32_WINNT 0x0A00` and `NTDDI_VERSION 0x0A000006`.
   - Uses `CreatePseudoConsole`, `ResizePseudoConsole`, and `ClosePseudoConsole`.
   - Creates child process suspended with `STARTUPINFOEXA` containing `PROC_THREAD_ATTRIBUTE_PSEUDOCONSOLE`.
   - Documented in `docs/RESPONSE_THREAT_MODEL_AND_TRUSTED_ORIGIN.md` that interactive shells require Windows 10 Version 1809 / Windows Server 2019+, while earlier Windows versions retain telemetry and snapshot capabilities with shells disabled.
3. **Hard Job Object Containment & Environment Sanitization**:
   - Every worker process is assigned to a dedicated Windows Job Object (`CreateJobObjectW`).
   - Limits set with `JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE | JOB_OBJECT_LIMIT_DIE_ON_UNHANDLED_EXCEPTION`.
   - Child process created with `bInheritHandles = FALSE`.
   - Environment block stripped to minimal required keys (`PATH=C:\Windows\System32;C:\Windows`, `SYSTEMROOT=C:\Windows`, `COMSPEC=C:\Windows\System32\cmd.exe`).
   - Working directory pinned to `C:\ProgramData\Ominull` (falling back to `C:\Windows\System32`).
   - Teardown calls `TerminateJobObject(hJob, 0)`, unconditionally killing the entire process tree and preventing orphaned child processes.
4. **Native WinHTTP WebSocket Transport**:
   - Establishes connection to `/api/v1/terminal/ws/agent?session_id=...&token=...` using `WinHttpOpen`, `WinHttpConnect`, `WinHttpOpenRequest`, and `WinHttpWebSocketCompleteUpgrade`.
   - Sends authentication headers `X-Device-Endpoint-ID` and `X-Terminal-Token`.
   - Relays bidirectional frames:
     - `stdout` from pseudoconsole pipe $\to$ Base64 encoded JSON frame $\to$ `WinHttpWebSocketSend`.
     - `stdin` from `WinHttpWebSocketReceive` $\to$ Base64 decoded $\to$ written to pseudoconsole input pipe.
     - `resize` from `WinHttpWebSocketReceive` $\to$ `ResizePseudoConsole`.
     - `close` or error $\to$ `WinHttpWebSocketClose`, `TerminateJobObject`, and clean handle release.
