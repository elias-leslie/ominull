## Claims

1. Every unreleased response mutation and query route (response jobs, response auth, evidence storage/export, terminal sessions/frames, scripts library/execution, and vulnerability correlation/sync) is gated behind `s.responseGate`.
2. When the gate is disabled (the default, without `--enable-unreleased-response` or `OMINULL_ENABLE_UNRELEASED_RESPONSE`), any request to any of the 26 endpoint paths returns HTTP `404 Not Found` with payload `{"error":"not_found","message":"response subsystem is disabled"}`.
3. No database rows, session objects, grants, or audit rows are created when a gated route is requested with valid admin credentials.
4. Heartbeat telemetry ingestion suppresses `response_offers` when the gate is off, ensuring agents are never offered pending jobs.
5. The gate can be enabled via flag `--enable-unreleased-response` or environment variable `OMINULL_ENABLE_UNRELEASED_RESPONSE=true` or programmatic method `srv.SetResponseEnabled(true)`.
