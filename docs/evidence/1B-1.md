## Status claimed

`verified`. Ephemeral Go in-memory maps have been replaced by a durable SQLite signer store interface (`Store`). All tenant response signing keys, operator memberships, authenticators, method policies, unlocked response sessions, replay protection state, recovery tokens, and security audit logs now survive authority process restart without losing state or silently invalidating unlocked sessions.

## Claims

1. Implemented durable [`hub/pkg/responseauth/store.go`](file:///srv/workspaces/projects/ominull/hub/pkg/responseauth/store.go) with pure-Go SQLite (`modernc.org/sqlite`) running in WAL mode with busy timeout handling. Defines 8 relational tables:
   - `tenant_keys`: Ed25519 signing keypairs and partition status.
   - `memberships`: Operator response authority roles (`response_admin`, `response_operator`).
   - `authenticators`: Enrolled credentials (TOTP, WebAuthn), failure counters, and lockouts.
   - `method_policies`: Allowed authentication methods, step-up requirements, session TTLs, and idle deadlines.
   - `response_sessions`: Authenticated browser sessions, public keys, allowed action kinds, expiry deadlines, and lock states.
   - `used_nonces`: Crash-resilient single-use replay protection for action proof nonces, grant nonces, and TOTP timesteps.
   - `recovery_tokens`: SHA-256 hashed single-use emergency enrollment tokens.
   - `signer_audit`: Append-only security audit log recording all authority events.
2. Refactored [`hub/pkg/responseauth/authority.go`](file:///srv/workspaces/projects/ominull/hub/pkg/responseauth/authority.go) to use `Store`, ensuring unlocked sessions survive restarts, replayed nonces are rejected across daemon restarts, and audit events are durably recorded.
3. Created comprehensive test suite in [`hub/pkg/responseauth/store_test.go`](file:///srv/workspaces/projects/ominull/hub/pkg/responseauth/store_test.go) proving:
   - Sessions remain valid and capable of signing grants across daemon restarts.
   - Proof nonces cannot be replayed even after an authority restart.
   - Emergency recovery tokens cannot be consumed more than once across restarts.
   - Session locks survive restarts.
   - Signer audit log captures all lifecycle events durably.
4. Deployed and verified on live production container LXC 150:
   - Database created at `/var/lib/ominull-response-authority/authority.db` owned by `ominull-authority:ominull-authority`.
   - Verified that tenant keys and audit records survive `systemctl restart ominull-response-authority.service`.
   - Proved zero regression to fleet telemetry and background diagnostic checks.
