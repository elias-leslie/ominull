## Status claimed

`verified`. Implemented cryptographic manifest signing, hub receipt signing, and offline verification. Extended endpoint registry in `hub/pkg/storage/storage.go` to store `evidence_signing_key`. Updated `hub/pkg/evidence/crypto.go` and `store.go` to manage dedicated Ed25519 hub receipt signing keys (`receipt.key`), sign canonical receipts (`OMINULL-RECEIPT-V2`), and verify length-prefixed canonical endpoint manifests (`OMINULL-MANIFEST-V2`). Updated `FinalizeBundle` to enforce endpoint manifest signature validation against registered endpoint public keys and durably persist signed receipts. Updated `ominullctl forensics verify` in `hub/cmd/ominullctl/main.go` to perform offline Ed25519 verification of manifest signatures, artifact digest verification against local extracted files, and receipt signature verification. Verified with comprehensive unit test suites in `store_test.go`, `evidence_test.go`, and `main_test.go`.

## Claims

1. **Endpoint Evidence Public Key Registration**:
   - `Endpoint` model in `hub/pkg/storage/storage.go` includes `evidence_signing_key`.
   - Migration ensures `evidence_signing_key` column exists in `endpoints` table.
   - `UpsertEndpoint`, `GetEndpoint`, and `ListEndpoints` persist and retrieve the endpoint evidence key.
2. **Canonical Manifest Signing & Hub Verification**:
   - `Manifest.CanonicalBytes()` encodes unambiguous length-prefixed fields (`OMINULL-MANIFEST-V2\x00` + bundle_id + endpoint_id + tenant_id + job_id + profile + collected_at + items).
   - `FinalizeBundle` verifies `ed25519.Verify(endpointPubKey, manifest.CanonicalBytes(), sig)`.
   - Unsigned or invalidly signed manifests fail closed with an error.
3. **Hub Receipt Signing & Chaining**:
   - Store initializes or loads `/var/lib/ominull/evidence/receipt.key` mode `0600`.
   - `Receipt.CanonicalBytes()` encodes unambiguous length-prefixed fields (`OMINULL-RECEIPT-V2\x00` + receipt_id + bundle_id + tenant_id + endpoint_id + manifest_sha + storage_sha + prev_receipt_sha + ingested_at).
   - Hub signs canonical bytes with `receiptKey`, populating `receipt_signature`.
   - Chaining queries previous receipt ordered deterministically by `ingested_at DESC, receipt_id DESC`.
4. **Offline Forensics Verification**:
   - `ominullctl forensics verify <manifest_file> [--key <endpoint_key>] [--receipt <receipt_file>] [--hub-key <hub_key>]`:
     - Parses `evidence.Manifest` and cryptographically verifies Ed25519 signature.
     - Validates local artifact files match catalog sizes and SHA-256 digests.
     - Verifies linked `evidence.EvidenceReceipt` manifest hash and hub Ed25519 signature.
     - Detects tampering in manifest, local files, or receipt.
