# Topology regions and evidence, v1.8.33

## Behavior

- Two-level region layout separates internal, explicit virtual, external and
  discovery groups. Cross-region traffic does not pull their internal layouts.
- Discovery starts collapsed. Regions can be dragged, pinned, collapsed and
  assigned through personal network-group overrides. Old saved views keep flat
  coordinates until the operator enables regions.
- Short labels, blue incoming and teal outgoing links relative to a reference,
  hover/focus evidence and keyboard-accessible link inspection reduce canvas copy.
  Arrows and a text key accompany colors. Full scope and process paths remain in
  the inspector. Address counts do not imply physical-device counts.

## Verification

Failing tests captured before implementation covered region assignment, decoupled
layout, explicit virtual classification, saved-state validation and compact labels.
Additional model regressions were also run against the committed baseline and
failed there. The baseline gutter test already passed; it is retained as a spacing
regression, not presented as a reproduced old failure.

Captured telemetry rendered through the real Store/Handler preview showed 785
addresses, 17 groups and three regions. Discovery collapse reduced the displayed
links from the flat overview while retaining directed cross-region aggregates.
Actual pointer dragging moved all six Internal groups by the same displacement;
External and Discovery coordinates were unchanged. Pinning all six retained their
coordinates through Arrange. Collapse rejected pinned contents and succeeded after
Unpin. HTTP-origin Save and reload restored all eight visible leaf positions and
zoom, plus three regions and collapse state.

Actual edge hover displayed ports, counts, measured bytes, domains and executable
names with reporter attribution. Keyboard focus in List view showed the same
content with `aria-describedby`; Escape hid it while retaining button focus.
Private screenshots and telemetry remain outside the repository. Rendering
captured IPv6 observations is not a new live IPv6 enforcement validation.

A longer hover check reproduced the five-second refresh dismissing tooltips and
clearing hover colors. The first release was stopped before packaging/deployment.
The fix preserves valid hover content and reference colors through polling, retains
keyboard focus after list refresh and keeps Escape-dismissed content dismissed.
Actual pointer checks retained one incoming and four outgoing links beyond a full
refresh. Moving the pointer inside the tooltip retained it through another refresh.
`scripts/verify-topology-hover.js` passed against the real browser route, checking
DOM replacement actually occurred before reporting successful focus/evidence
retention. The same check verifies Escape remains dismissed after another refresh.

Final preview at 1024×768 measured 11.28px group text; 1440px review also verified a
personal virtual-region override. No network configuration or policy changed.

Legacy-view runtime check used a saved state without region fields. Loading it
kept the graph flat, restored its pinned position exactly and retained zoom 0.8.
The temporary fixture view was deleted after the check.
