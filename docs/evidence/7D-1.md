# Evidence: Slice 7D — Web Console Software Inventory & Vulnerability Correlation UI with Chrome 150 CDP Rehearsal

## 1. Overview

Slice 7D completes Phase 7 of the Next-Generation Forensics and Response architecture by delivering the Web Console operator surface for:
1. **Installed Software Inventory Inspection**: Detailed host package listings on endpoint asset route drawers, featuring authoritative/inferred confidence badges, packaging system badges, install scope indicators, raw vs normalized version tracking, and live interactive search filtering.
2. **Active Vulnerability Feed Snapshot Lifecycle Display**: Real-time snapshot metadata strip on the Forensics view indicating snapshot ID, NVD 2.0 CVE count, CISA KEV exploit count, EPSS prediction count, and activation timestamp.
3. **Interactive Feed Synchronization Modal**: Modal allowing operators to trigger upstream feed synchronization across NVD, CISA KEV, and EPSS with customizable endpoints and record bounds.
4. **Explainable Vulnerability Investigation & Correlation Table**: Prioritized vulnerability match table featuring CVSS severity badges, composite priority scores (0.0–100.0), CISA KEV exploitation badges, EPSS prediction badges, and correlation verdict badges (`Affected`, `Possible`, `Not Affected`, `Inconclusive`).
5. **Explainable Audit Evidence Sheet (`.sheet-wide`)**: Modal providing full audit reproducibility for any vulnerability match candidate, displaying detected product and version, raw installed package string, package manager source, target CPE criteria pattern, vulnerable version range boundaries, natural language comparison rationale, and raw structured JSON audit evidence.
6. **Automated Headless Google Chrome 150 CDP Verification**: Full-browser automated rehearsal verifying all UI components, state polling, feed sync triggers, modal opening, table rendering, and search filtering against live LXC 150 (`ominull-hub`).

## 2. Implementation Architecture

### 2.1 Web Console Frontend UI Components (`hub/pkg/server/web/app.js`)

- **`vulnStatusBadge(status)`**:
  - Color-coded verdict pill badge using `data-status` attribute:
    - `matched`: Red border and tinted background ("Affected").
    - `not_affected`: Green border and tinted background ("Not Affected").
    - `possible`: Amber border and tinted background ("Possible").
    - `insufficient_data`: Muted gray border and background ("Inconclusive").
- **`priorityScoreBadge(score)`**:
  - Monospace composite priority score pill badge:
    - Critical (≥ 70.0): Red high-contrast border and text (`.priority-crit`).
    - High (≥ 40.0): Amber border and text (`.priority-high`).
    - Medium / Low: Surface border and neutral text.
- **`cisaKevBadge()`**:
  - High-visibility threat alert badge indicating confirmed active in-the-wild exploitation via CISA Known Exploited Vulnerabilities catalog.
- **`epssBadge(score)`**:
  - Exploit Prediction Scoring System probability badge rendering percentage (e.g. `EPSS 4.5%`, `EPSS 97.5%`) with purple styling.
- **`softwareSourceBadge(source)` & `softwareScopeBadge(scope)`**:
  - Source tags (`dpkg`, `rpm`, `win_registry`, `win_package`, `macos_app`) and scope tags (`system`, `user`).
- **`openMatchEvidenceSheet(v)`**:
  - Centered responsive sheet dialog displaying:
    - Correlation verdict, CVE ID, CVSS severity, and composite priority score breakdown (`(CVSS × 6.0 + KEV × 25.0 + EPSS × 15.0) × confidence`).
    - Threat intelligence flags (CISA KEV and EPSS).
    - Endpoint ID, detected package name, normalized version, and raw installed version.
    - Matching Criteria & Version Boundaries card: CPE criteria string, vulnerable version range, and comparison verdict note (`.note-crit`, `.note-ok`, `.note-warn`).
    - Explainable Audit Evidence box (`.evidence-detail-box`) with scrollable, formatted raw JSON.
- **`openSyncFeedModal()`**:
  - Modal sheet with toggleable online fetch, NVD, CISA KEV, and EPSS endpoint inputs, and max NVD results constraint.
- **`softwareInventoryCard(asset)`**:
  - Installed software inventory section embedded in `renderRoute(asset)`.
  - Displays package count summary, real-time client search input filtering across product, vendor, version, and source.
  - Table rendering Package/Product, Version (with raw version hint), Source, Architecture, Scope, Confidence (`authoritative` vs `inferred`), and Observed timestamp.
- **Upgraded `renderForensics()`**:
  - Embeds active feed snapshot strip (`.snapshot-meta-strip`) with active snapshot ID, NVD CVE count, KEV exploit count, EPSS score count, and "Sync Feeds…" trigger button.
  - Adds verdict filter buttons: "All Verdicts", "Affected Only", "Possible", "Not Affected".
  - Upgraded table rendering CVE, Severity, Priority Score, Threat Intelligence Flags, Verdict Badge, Product, Version, Match Reason, and "Explain" action button.
