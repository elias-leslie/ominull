## Status claimed

`verified`. Implemented the Linux interactive pseudoterminal worker in `agent/include/terminal_linux.h` and integrated into `agent/linux/main.c`. Enforced strict allowlist validation allowing exclusively `/bin/sh` and `/bin/bash` with executable checks, rejecting arbitrary executables, shell commands, relative paths, or environment overrides. Allocated the pseudoterminal via `forkpty(3)` with dedicated process group leadership (`setpgid(0, 0)`), closed inherited file descriptors, and sanitized the execution environment (`clearenv()` with strictly defined `TERM`, `PATH`, `HOME`, `USER`, and `SHELL`). Implemented dynamic window resize propagation via `TIOCSWINSZ` with bounds checks. Implemented fail-closed child-tree process termination, sending `SIGTERM` followed by unconditional `SIGKILL` to the child's process group (`kill(-child_pid, SIGKILL)`), preventing orphaned background subshells. Implemented full-duplex WebSocket relay over authenticated transport via libcurl `CURLOPT_CONNECT_ONLY` and RFC 6455 framing. Verified via C unit tests (`test_terminal_linux`), full Go end-to-end loopback integration test under race detection (`TestLinuxTerminalWorker_LoopbackWithPty`), package builds, and package lifecycle tests.

## Claims

1. **Strict Program Allowlist (`agent/include/terminal_linux.h`)**:
   - Only `/bin/sh` and `/bin/bash` are permitted.
   - `Terminal_IsAllowedProgram` verifies that the binary path exactly matches `/bin/sh` or `/bin/bash` and possesses executable permissions (`access(program, X_OK) == 0`).
   - Rejects relative paths, other shells (`/bin/dash`, `/bin/zsh`), command arguments (`/bin/sh -c ...`), arbitrary executables, and null/empty inputs.
2. **Pseudoterminal Allocation & Environment Sanitization**:
   - Uses `forkpty(3)` to allocate the master/slave pseudoterminal pair.
   - Child process runs `setpgid(0, 0)` to establish an independent process group.
   - Child executes `clearenv()` and sets only minimal required environment variables (`TERM=xterm-256color`, `PATH=/usr/bin:/bin:/usr/sbin:/sbin`, `HOME=/root`, `USER=root`, `SHELL=program`).
   - Child sets safe working directory (`/var/lib/ominull` or `/root`).
   - Automated unit tests verify that parent environment variables and secrets are completely eradicated from the child.
3. **Window Resize Propagation**:
   - WebSocket `resize` frames deliver terminal dimensions (`rows`, `cols`).
   - Worker validates dimensions within bounds ($1 \le \text{rows} \le 500$, $1 \le \text{cols} \le 500$).
   - Calls `ioctl(master_fd, TIOCSWINSZ, &ws)`.
   - Verified that `ioctl(master_fd, TIOCGWINSZ)` accurately reflects resized dimensions.
4. **Child-Tree Process Termination Containment**:
   - On session teardown (operator close, disconnect, error, or exit), `Terminal_KillChildTree` sends `SIGTERM` followed by unconditional `SIGKILL` to `-child_pid` (the entire process group).
   - Reaps child with `waitpid(child_pid, &status, 0)` preventing zombie processes.
   - Automated test verifies that background processes spawned inside the shell (e.g. `sleep 300 &`) are cleanly terminated without escaping.
5. **Authenticated WebSocket Relay Loopback**:
   - Connects to `/api/v1/terminal/ws/agent?session_id=...&token=...` via libcurl `CURLOPT_CONNECT_ONLY, 1L`.
   - Sends standard RFC 6455 HTTP upgrade request with dynamic nonce key.
   - Runs full-duplex non-blocking `poll()` relay:
     - `stdout` from `master_fd` $\to$ Base64 encoded JSON frame $\to$ masked WebSocket frame.
     - `stdin` from WebSocket frame $\to$ Base64 decoded $\to$ written to `master_fd`.
     - `resize` from WebSocket frame $\to$ `ioctl(TIOCSWINSZ)`.
     - `close` or EOF $\to$ clean teardown.
   - Verified via end-to-end integration test `TestLinuxTerminalWorker_LoopbackWithPty` in `hub/pkg/server/terminal_linux_worker_test.go` communicating bidirectionally with real shell under Go race detection.
