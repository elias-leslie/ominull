# v1.8.31 topology verification

## Synthetic runtime

Viewed the real Go HTTP handler in managed headless Chrome with 66 synthetic
hosts across nine groups, IPv4/IPv6 observations, reported domains and process
paths. These are fixtures, not production IPv6 validation.

- Viewed overview at 1024×768, 1280×900 and 1440×900. Group cards and controls fit.
- Domain search selected the expected two hosts and one directed link.
- Host inspector showed domain provenance, executable path and reporting endpoint.
- List Inspect controls worked at 1024 pixels after correcting inherited table width.
- Mouse box selection selected all nine clusters. Drag moved all nine by equal offsets.
- Mouse drag and Undo restored prior positions. Pin plus Arrange retained coordinates.
- A concurrent saved-view update returned HTTP 409. The UI retained its unsaved
  layout and error across polling after correcting a disappearing status message.
- Saved view reload restored positions, pins and zoom. Navigation to Traffic and back
  retained unsaved search and list state in memory.
- Saved-view creation passed on a non-secure HTTP origin where randomUUID is
  unavailable, using getRandomValues. The resulting view retained nine positions.
- Keyboard-accessible list exposes host/group inspection without relying on canvas.

The final bundled renderer and worker benchmark created 1,500 nodes and 3,000
links, computed all 1,500 positions, applied them, fitted the viewport and waited
for two animation frames in **1,592.6 ms**. This synthetic graph and local machine
met the two-second target; this is not a universal latency guarantee. The
repeatable fixture is `scripts/benchmark-topology.js`: evaluate it in an isolated
browser showing the console. It temporarily mounts and then removes its graph. Separate
10,000-host projection tests verify progressive expansion rather than drawing
all hosts at once.

## Correctness and gates

Fail-first tests cover all IPv4/IPv6 loopback peers, stable retained asset identity,
opposite directions, domain/process evidence, malformed view state and gateway
agent evidence. Owner/revision tests cover cross-operator isolation, forged owner
headers, stale writes, auditor write rejection and endpoint-key access rejection.
Protocol-filter regression requires filtered byte and observation totals.

Full Go race suite passed; server package took 216.688 seconds. Go vet, native
build, frontend syntax/model tests, deterministic dependency bundle checks,
version check and managed project checks passed before release. Staged secret
scan found no leaks; history scan found only the known removed placeholder in
commit 665795f. Canonical release reruns retained gates on the release version.

## Limits

Domains and executable paths are observed associations, not device identity or
proof of a unique process instance. Counts are telemetry observations and may
include multiple reporters. Search matches host pairs; pair totals retain their
window observations. At most 20,000 recent grouped evidence relations are returned,
with explicit truncation. Canvas expansion draws at most 1,500 individual hosts
and 3,000 links. Pins protect arrangement, not policy. Personal saved views require
explicit Save; unsaved in-memory work does not survive a page reload.

Topology uses canonical event queries with the existing 60-second response cache.
It adds no rollup migration. Frozen interval bounds are shared by graph and evidence;
the two reads are not an atomic database snapshot. Live query timing is recorded
separately from browser rendering.

## Live deployment

Canonical release deployed hub 1.8.31, passed both canaries, and rolled retained
agents. First live workspace response took 1.945494 seconds and returned 785 nodes,
813 directed pairs, 11,637 evidence relations and 5,384,751 bytes. Of those relations,
519 had domain evidence and 11,630 had process paths; no truncation was reported.
The browser loaded 1.8.31 and rendered 17 groups with 26 directed aggregate links,
without browser errors. These are live route/UI observations, not IPv6 enforcement
tests. The 17-group screenshot exposed small labels from a wide disconnected layout;
a readability follow-up remains before declaring the topology work complete.
