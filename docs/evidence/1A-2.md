## Status claimed

`verified`. The response authority is packaged and running under its own distinct unprivileged system identity (`ominull-authority:ominull-authority`). Signing keys and state directory `/var/lib/ominull-response-authority` are mode `0700` and unreadable by the hub user `ominull`. The hub process communicates exclusively across a restricted local Unix domain socket (`/run/ominull-response-authority/authority.sock`, mode `0660`). The response authority has zero filesystem access to the hub database or package directories.
