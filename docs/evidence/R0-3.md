## Claims

1. Fixed compiler error in `cmdVulnerabilities` (`main.go:718`, formerly line 750: `declared and not used: raw`).
2. Removed forbidden `shell open` and `shell exec` subcommands from `cmdShell`. Invoking them returns the standard usage error `usage: ominullctl shell sessions|show|close <session_id>`.
3. Eliminated cleartext terminal connection token printing to stdout (formerly `main.go:718`).
4. Removed the `OMINULL_API_KEY` plaintext environment variable fallback (`main.go:174`). Authentication credentials must be supplied via `--api-key-file` or `OMINULL_API_KEY_FILE` (defaulting to `/etc/ominull/admin.key`).
5. Fixed `main_test.go:54` assignment mismatch and added unit tests covering:
   - Flag parsing with trailing subcommand arguments
   - Enforcement of no plaintext `OMINULL_API_KEY` environment fallback
   - Rejection of forbidden `shell open`, `exec`, and unknown subcommands
6. `ominullctl` builds cleanly with `go build ./cmd/ominullctl`.
