## Status claimed

`verified`. Implemented the native Linux script execution worker in pure C (`agent/include/script_exec_linux.h`) and wired it into `ProcessResponseOffers` in `agent/linux/main.c`:
1. Strict interpreter allowlisting: strictly enforces `/bin/sh`, `/bin/bash`, and `pwsh` (all unallowlisted interpreters rejected with exit code 126 before execution).
2. Bounded payload parser with JSON unescaping: parses `script_id`, `version`, `script_digest`, `interpreter`, `source` (up to 64 KiB), `parameters` (up to 16 KiB), `timeout_seconds`, and `max_output_bytes`.
3. In-process SHA-256 digest recomputation: computes the SHA-256 digest of the unescaped script source and verifies it against the signed `script_digest` from the grant payload (mismatch rejected with exit code 125).
4. Parameter delivery without template substitution: writes typed parameters to a private parameter file (`ominull_params_<job_id>.json`, mode `0600`) and exports individual parameters into the sanitized child environment (`OMINULL_PARAM_<NAME>` and `<NAME>`), ensuring ZERO textual template injection into script source.
5. Process containment:
   - Dedicated child process group (`setpgid(0, 0)`) for complete tree termination.
   - File descriptor isolation: closes all descriptors above stderr (`close(fd > 2)`).
   - Sanitized environment: `clearenv()` followed by minimal `PATH`, `HOME`, `USER`, `LANG`, and script identifiers.
   - Explicit safe working directory: state directory (`/var/lib/ominull` or fallback `/tmp`).
   - CPU resource bounding (`RLIMIT_CPU` set to timeout + 5s).
   - Hard execution timeout escalation: monitors child execution with millisecond precision, escalating from `SIGTERM` to `SIGKILL` on timeout and reporting standard exit code 124.
6. Bounded output capture: captures combined stdout and stderr up to `max_output_bytes` (up to 5 MiB cap), appending honest truncation notice if exceeded.
7. Automated cleanup: unlinks temporary execution script and parameter files upon termination.
8. Daemon dispatch wiring: hooked `script_exec` into `ProcessResponseOffers` in `agent/linux/main.c`, reporting complete results (`stdout`, `exit_code`, `duration_ms`, `state`, `error_code`) back to the hub via `POST /api/v1/response/jobs/result`.

## Claims

1. **Interpreter Allowlisting**:
   - `ScriptExec_IsAllowedInterpreter` allows only `/bin/sh`, `/bin/bash`, `/usr/bin/sh`, `/usr/bin/bash`, and `pwsh`.
   - Hostile binaries (`/usr/bin/python3`, `/bin/zsh`, `/usr/bin/perl`, `sudo`) are rejected before spawning any child process.

2. **Source Digest Defense-in-Depth**:
   - The worker independently recomputes the SHA-256 hash of the decoded script source using in-process `Response_SHA256_Sum` and compares it with `script_digest`. Tampered payloads are rejected with exit code 125.

3. **Safe Parameter Delivery**:
   - The script source is executed verbatim without any textual macro or template substitution.
   - Parameters are written to `/var/lib/ominull/ominull_params_<job_id>.json` (mode `0600`).
   - The parameter file path is exposed via `OMINULL_PARAMS_FILE`.
   - Individual parameters are exported into the sanitized child environment as `OMINULL_PARAM_<NAME>`, `OMINULL_PARAM_<UPPER_NAME>`, and `<NAME>`.

4. **Tree Process Containment & Timeout Escalation**:
   - Child process calls `setpgid(0, 0)` so that sub-processes (e.g. `sleep`, child shells) belong to the dedicated process group.
   - When execution exceeds `timeout_seconds`, parent sends `SIGTERM` to `-child_pid`, grants 250ms grace period, then issues `SIGKILL` to `-child_pid`.
   - All child processes are terminated, preventing background leakage.
   - Timed-out jobs report standard Unix timeout exit code 124 and `error_code: "TIMED_OUT"`.

5. **Bounded Output & JSON Escaping**:
   - Reads from pipe are bounded to `max_output_bytes`.
   - Output exceeding the cap sets `truncated = true` and appends `\n[... output truncated at byte limit ...]\n`.
   - Standard output is escaped via `ScriptExec_EscapeJSON` before HTTP transport.
