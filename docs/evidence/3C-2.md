## Claims

1. **Fully Vendored & Pinned Terminal Engine (Zero CDN)**:
   - xterm.js v6.0.0 (`vendor/xterm.js`, `vendor/xterm.css`) and Addon-Fit v0.11.0 (`vendor/addon-fit.js`) vendored locally into `hub/pkg/server/web/vendor/` with upstream MIT license file (`vendor/LICENSE.xterm.txt`).
   - Served directly via hub single-binary embedding (`go:embed web`).
   - Proved 0 external CDN requests in headless Google Chrome network audit.
   - Versioned cache-busting URLs tested in `TestTheConsoleAsksForItsAssetsByVersion`.

2. **Honest Session UI & Invariant Display**:
   - Terminal window (`.sheet-terminal`) renders honest session metadata:
     - Endpoint identity: hostname, IP, and endpoint ID.
     - Execution supervisor identity: `root` on Linux, `LocalSystem` on Windows.
     - Allowlisted program choice: e.g. `/bin/bash` or `powershell.exe`.
     - Caps & limits: maximum duration (60m), idle timeout (15m), and tenant quota slots (e.g. `0/4`).
     - Evidence & audit indicator: `Frames: N (AES-GCM encrypted)`.
     - Live connection status: `Connecting to Relay…`, `Awaiting Agent Connection`, `Live Pseudoterminal Active`, or `Session Terminated`.

3. **Untrusted Terminal Text & Safe Execution**:
   - `allowProposedApi: false` enforces rejection of experimental/unvetted terminal capabilities.
   - Terminal emulator disables auto-clipboard access, window manipulation, and URL navigation escape sequences.
   - Binary stdout data decoded from Base64 and written safely via typed byte arrays.

4. **Interactive Controls & Clean Lifecycle**:
   - `Ctrl+C`: dispatches `SIGINT` (`\x03`) to the remote pseudoterminal process group.
   - `Ctrl+D`: dispatches EOF (`\x04`).
   - `Clear`: resets local viewport without affecting remote shell session.
   - `Close Session`: confirms with operator, transmits `FrameClose`, issues `DELETE /api/v1/terminal/sessions?id=...`, terminates remote child process tree, and purges relay state.
   - `Detach Viewer`: closes local WebSocket and disposes xterm instance without terminating remote session.
   - Clean lifecycle hook `sheetEl._cleanup` disposes xterm and closes WebSocket on modal dismiss.
