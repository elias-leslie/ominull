## Status claimed

`verified`. Implemented the authenticated full-duplex WebSocket relay engine in `hub/pkg/terminal/relay.go` using `github.com/gorilla/websocket`. Added operator and agent WebSocket endpoints (`/api/v1/terminal/ws/operator` and `/api/v1/terminal/ws/agent`), pairing coordination, flow control with 1 MiB queue caps, 25-second ping/pong heartbeats, and clean bidirectional teardown. Enforced the relay token handling invariant: plaintext tokens are never stored in memory long-term, are hashed via SHA-256 (`TokenHash`), verified in constant-time, delivered to the operator via a secure HttpOnly attach cookie, and excluded from all JSON DTOs and `Summary()` responses. Verified via unit and server integration tests with `-race`, proving `stdin`, `stdout`, and `resize` frame relay and clean closure propagation.

## Claims

1. **Authenticated WebSocket Relay Engine (`hub/pkg/terminal/relay.go`)**:
   - Built `PairedRelay` managing operator and agent WebSocket connections with concurrent read and write pumps.
   - Configured `websocket.Upgrader` with 32 KiB read/write buffers.
   - Enforced 25-second ping intervals and 60-second pong deadlines to maintain state across intermediate proxies and detect dead peers.
   - Implemented 1 MiB per-direction queue buffer cap (`MaxQueueBytes`) to protect against memory exhaustion.
2. **Strict Relay Token Security & Zero-Exposure Invariant**:
   - `TerminalSession` stores `TokenHash` (`json:"-"`); plaintext tokens are never serialized in DTOs.
   - `ValidateToken` performs constant-time SHA-256 comparison against `TokenHash`.
   - `POST /api/v1/terminal/sessions` issues the token to the operator browser via an `HttpOnly`, `SameSite=Strict`, `Secure` cookie (`ominull_terminal_token`).
   - Automated tests verify that neither `connect_token` nor `token_hash` appear in JSON responses or session summaries.
3. **Loopback Relay Verification (`hub/pkg/terminal/relay_test.go`)**:
   - `TestTerminalRelay_AuthenticatedLoopback`: Verified operator WSS attach, agent WSS attach, session transition to `active`, bidirectional data transfer (`stdin` operator $\to$ agent, `stdout` agent $\to$ operator), dynamic `resize` frame propagation, and clean close propagation.
   - `TestTerminalRelay_ForbiddenFrameTypes`: Verified fail-closed termination when a party attempts to send an unpermitted frame type (operator sending `stdout`).
4. **Server Integration (`hub/pkg/server/terminal_handlers.go`, `server.go`, `terminal_test.go`)**:
   - Registered `/api/v1/terminal/ws/operator` and `/api/v1/terminal/ws/agent`.
   - Added end-to-end integration test `TestServer_TerminalWebSocketRelay` verifying full HTTP session creation, cookie issuance, WebSocket upgrades, bidirectional frame transfer, and clean teardown through the full server router.
   - Verified clean package builds and Debian package lifecycle.
