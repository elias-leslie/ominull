## Status claimed

`verified`. Implemented the native Windows script execution worker in pure C (`agent/include/script_exec_windows.h`) and wired it into `ProcessResponseOffersWindows` in `agent/src/response_windows.c`:
1. Strict interpreter allowlisting: strictly enforces `powershell.exe`, `powershell`, `cmd.exe`, `cmd`, and `pwsh.exe` (PowerShell Core, only when detected on disk). All unallowlisted interpreters (e.g. `/bin/sh`, `/bin/bash`, `calc.exe`, `notepad.exe`, `cscript.exe`, `wscript.exe`, `python.exe`) or inputs containing subshell flags, semicolons, pipes, or redirects are rejected before execution.
2. Bounded payload parser with JSON unescaping: parses `script_id`, `version`, `script_digest`, `interpreter`, `source` (up to 64 KiB), `parameters` (up to 16 KiB), `timeout_seconds`, and `max_output_bytes`.
3. In-process SHA-256 digest recomputation: computes the SHA-256 digest of the unescaped script source using in-process `Response_SHA256_Sum` and verifies it against the signed `script_digest` from the grant payload (mismatch rejected immediately with error code `SCRIPT_DIGEST_MISMATCH` without creating files or spawning processes).
4. Parameter delivery without template substitution: writes typed parameters to a private parameter file (`C:\ProgramData\Ominull\ominull_params_<job_id>.json`) and exports individual parameters into the sanitized child environment block (`OMINULL_PARAM_<NAME>`, `OMINULL_PARAM_<UPPER_NAME>`, and `<NAME>`), ensuring ZERO textual template injection into script source.
5. Windows Job Object process containment:
   - Dedicated Windows Job Object with `JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE | JOB_OBJECT_LIMIT_DIE_ON_UNHANDLED_EXCEPTION`.
   - Suspended process creation (`CREATE_SUSPENDED`), assigned to the Job Object before thread resumption.
   - Anonymous pipe redirection capturing combined stdout and stderr.
   - Dedicated `NUL` standard input handle preventing blocking on interactive prompts.
   - Sanitized Win32 environment block containing solely necessary system variables (`SystemRoot`, `SystemDrive`, `ComSpec`, `PATH`, `TEMP`, `TMP`, `PSExecutionPolicyPreference=Bypass`) and Ominull job parameters.
   - Explicit safe working directory: `C:\ProgramData\Ominull` (or system temp directory).
   - Millisecond-accurate execution timeout monitoring: terminates the job object tree via `TerminateJobObject(hJob, 124)` on expiration, reporting exit code 124 and `error_code: "TIMED_OUT"`.
6. Bounded output capture: captures combined stdout and stderr up to `max_output_bytes` (up to 5 MiB cap), appending honest truncation notice if exceeded.
7. Automated cleanup: removes temporary execution script (`ominull_script_<job_id>.<ps1|cmd>`) and parameter files (`ominull_params_<job_id>.json`) upon termination.
8. Daemon dispatch wiring: hooked `script_exec` into `ProcessResponseOffersWindows` in `agent/src/response_windows.c`, executing within a dedicated worker thread and reporting complete results (`stdout`, `exit_code`, `duration_ms`, `state`, `error_code`) back to the hub via `Hub_PostPathJSON` to `POST /api/v1/response/jobs/result`.

## Claims

1. **Interpreter Allowlisting**:
   - `ScriptExec_IsAllowedInterpreterWindows` resolves executables to canonical system paths (`%SystemRoot%\System32\cmd.exe`, `%SystemRoot%\System32\WindowsPowerShell\v1.0\powershell.exe`, or detected `pwsh.exe`).
   - Hostile binaries (`calc.exe`, `notepad.exe`, `cscript.exe`, `wscript.exe`, `python.exe`) or shell injection characters (`|`, `;`, `&`, `>`, `<`) are rejected before spawning any process.

2. **Source Digest Defense-in-Depth**:
   - The worker independently recomputes the SHA-256 hash of the decoded script source using in-process `Response_SHA256_Sum` and compares it with `script_digest`. Tampered payloads are rejected with exit code 1 and error code `SCRIPT_DIGEST_MISMATCH` before creating files.

3. **Safe Parameter Delivery**:
   - The script source is executed verbatim without any textual macro or template substitution.
   - Parameters are written to `C:\ProgramData\Ominull\ominull_params_<job_id>.json`.
   - The parameter file path is exposed via `OMINULL_PARAMS_FILE`.
   - Individual parameters are exported into the sanitized child environment block as `OMINULL_PARAM_<NAME>`, `OMINULL_PARAM_<UPPER_NAME>`, and `<NAME>`.

4. **Job Object Containment & Timeout**:
   - Child process runs inside a dedicated Windows Job Object configured with `JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE`.
   - When execution exceeds `timeout_seconds`, the parent invokes `TerminateJobObject(hJob, 124)`, terminating the entire process tree including any child processes spawned by the script.
   - Timed-out jobs report exit code 124 and `error_code: "TIMED_OUT"`.

5. **Bounded Output & JSON Escaping**:
   - Reads from anonymous pipe are bounded to `max_output_bytes`.
   - Output exceeding the cap sets `truncated = true` and appends `\n[...output truncated by ominull worker...]\n`.
   - Output is safely escaped via `ScriptExec_EscapeJSONWin` before HTTP transport.
