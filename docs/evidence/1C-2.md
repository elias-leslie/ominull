## Status claimed

`verified`. Implemented independent server-side SHA-256 action digest recomputation across all response routes (`/api/v1/response/jobs`, `/api/v1/scripts/run`, `/api/v1/terminal/sessions`), rejecting client-supplied digest mismatches and proof digest mismatches. Implemented `X-Operator-ID` stripping in `authMiddleware` and `deviceOrLegacyMiddleware`, binding operator identity exclusively to authenticated session credentials.

## Claims

1. **Independent Server-Side Digest Recomputation**:
   - **Generic Response Jobs:** Server computes `sha256(req.PayloadJSON)` independently. Rejects mismatched client `action_digest` or `proof.action_digest` with HTTP 400.
   - **Script Execution:** Server serializes canonical `response.ScriptExecPayload` from the registered script version and recomputes the SHA-256 digest prior to requesting grant signing from the response authority.
   - **Terminal Sessions:** Server serializes canonical `response.TerminalSessionPayload` and recomputes the SHA-256 digest prior to requesting grant signing.
2. **Identity-Header Stripping**:
   - `authMiddleware` and `device_auth` delete `X-Operator-ID` on ingress along with `X-Role`, `X-Tenant-ID`, `X-Username`, `X-User-ID`, `X-Client-CN`, and `X-Device-Endpoint-ID`.
   - `s.operatorFromRequest(r)` binds operator identity exclusively to the securely verified session context (`X-Username` set after JWT/cookie/key verification).
   - Forged `X-Operator-ID` headers are ignored and stripped.
3. **Testing & Live Deployment**:
   - Tested and verified locally with Go race detector (`go test -race ./pkg/server/...`).
   - Verified clean Debian package lifecycle build.
   - Deployed to LXC 150; verified fail-closed gating of response routes and continuous fleet telemetry streaming.
