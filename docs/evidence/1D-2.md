## Claims

1. **Windows Response Dispatcher & Bounded Offer Parser**:
   - Parses `response_offers` from the heartbeat response using the fixed schema parser (`ParseResponseOffers`).
   - Bounds: at most `MAX_RESPONSE_OFFERS` (4) offers, maximum 64KB payload per offer.
   - Strictly validates `job_id`, `lease_id`, `kind`, `grant` (version 2, grant_id, tenant_id, endpoint_id, action_kind, action_digest, operator_id, response_session_id, issued_at, expires_at, nonce, signer_key_id, signature), and `payload_json`.
2. **In-Process Pure-C Ed25519 Verifier (`agent/include/ed25519_verify.h`)**:
   - Zero external runtime DLL or CLI dependencies; portable pure-C implementation of RFC 8032 Edwards25519 verification.
   - Loads tenant response public key from `C:\ProgramData\Ominull\response.pub` (supporting PEM, Hex, and raw 32-byte formats).
   - Verifies canonical binary encoding `OMINULL-ENDPOINT-GRANT-V2` (`EncodeGrantV2Canonical`).
   - Validates `grant->version == 2`, strict endpoint ID binding (`grant->endpoint_id == config->endpoint_id`), timestamp validity window (+/- 60s tolerance), and recomputed payload SHA-256 digest equality.
3. **Durable Win32 Locked Replay Cache**:
   - State file: `C:\ProgramData\Ominull\replay_cache.state`.
   - POSIX/Win32 file concurrency: `CreateFileA` with `GENERIC_READ | GENERIC_WRITE` and `FILE_SHARE_READ`, followed by `LockFileEx(LOCKFILE_EXCLUSIVE_LOCK)`.
   - Checks against recorded `grant_id` and `nonce` entries; rejects replays.
   - Prunes expired records and flushes synchronously to disk with `FlushFileBuffers` before releasing lock with `UnlockFileEx`.
4. **Contained Worker Execution with Windows Job Objects**:
   - Workers are executed in an isolated Windows Job Object (`CreateJobObjectW`).
   - Extended limit flags: `JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE | JOB_OBJECT_LIMIT_DIE_ON_UNHANDLED_EXCEPTION`.
   - Child process created suspended (`CREATE_SUSPENDED | CREATE_NO_WINDOW | CREATE_BREAKAWAY_FROM_JOB`) with `bInheritHandles = FALSE`.
   - Sanitized environment block containing only minimal system directories (`PATH=C:\Windows\System32;C:\Windows`, `SYSTEMROOT=C:\Windows`).
   - Working directory explicitly restricted to `C:\ProgramData\Ominull`.
   - Kill-on-cancel / timeout enforcement: `TerminateJobObject(hJob, 1)`.
   - Never synthesizes success without actual execution.
5. **WinHTTP Response Transport & Confidentiality**:
   - Implemented `Hub_PostPathJSON` in `agent/src/hub_client.c` supporting device credential authentication (`X-Ominull-Device-Credential` or `X-API-Key`) and TLS client certificate attachment.
   - Gated acknowledgments (`POST /api/v1/response/jobs/ack`) only upon successful grant verification and replay check.
   - Submits results (`POST /api/v1/response/jobs/result`) with observed exit code and execution duration.
   - Zero confidential data leakage (no job IDs, payloads, or tokens printed to stdout, service log, or Event Log).
6. **Zero Warnings & Build Verification**:
   - Compiles cleanly under MinGW GCC with `-Wall -Wextra -Wformat=2 -O2` with zero warnings.
   - Full test suite in `agent/tests/test_response_dispatcher_win.c` passes under Wine.
   - Built Windows MSI package (`dist/ominull-agent-windows-1.8.3.msi`) and verified package lifecycle.
