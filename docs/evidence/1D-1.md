## Status claimed

`verified`. Implemented the Linux response dispatcher including bounded offer parser over a fixed schema (max 4 offers, max 64KB payload), pure-C in-process SHA-256 digest recomputation, canonical Ed25519 `EndpointGrant` V2 cryptographic verification, durable locked replay cache with expiration pruning (`replay_cache.state`), strict acknowledgment gating, child worker containment (process groups, closed descriptors, wiped environment, resource limits), and confidential zero-logging of job identifiers or action payloads.

## Claims

1. **Bounded Offer Parser**:
   - Parses the `response_offers` array in the heartbeat response without substring scanning collisions (`strstr` across document).
   - Bounds: at most `MAX_RESPONSE_OFFERS` (4) per heartbeat, payload capped at 64KB.
   - Enforces fixed schema: strictly validates `job_id`, `lease_id`, `kind`, `grant` (version 2, grant_id, tenant_id, endpoint_id, action_kind, action_digest, operator_id, response_session_id, issued_at, expires_at, nonce, signer_key_id, signature), and `payload_json`.
   - Rejects malformed or truncated offers safely without memory corruption.
2. **Cryptographic Grant Verifier**:
   - Reads tenant response public key from `/etc/ominull/response.pub`.
   - Checks `grant->version == 2` and strictly verifies `grant->endpoint_id == config->endpoint_id`.
   - Recomputes SHA-256 over `payload_json` using in-process FIPS 180-4 SHA-256 and validates equality with `grant->action_digest`.
   - Checks expiration window: validates that current time falls between `issued_at - 60s` and `expires_at + 60s`.
   - Serializes canonical binary encoding (`EncodeGrantV2Canonical`) and verifies the detached Ed25519 signature.
3. **Durable Replay Cache**:
   - State file: `/var/lib/ominull/replay_cache.state` (mode `0600`).
   - Concurrency control: POSIX advisory file locking (`flock(fd, LOCK_EX)`).
   - Prevents replay of seen `grant_id` or `nonce` values.
   - Durability: synchronous write (`fsync`) before acknowledgment.
   - Prunes expired cache records upon each update.
4. **Worker Dispatch & Containment**:
   - ACKs only after grant verification and replay cache check succeed.
   - Dispatches workers in a contained child process:
     - New process group (`setpgid(0, 0)`).
     - Inherited descriptors closed (`close(3..1024)`).
     - Environment wiped (`clearenv()`), setting only minimal safe PATH and HOME.
     - Safe directory (`chdir("/var/lib/ominull")`).
     - Resource limits applied (`setrlimit(RLIMIT_CPU, 60)`).
   - Never synthesizes success without execution.
   - Zero confidential data leakage (no job IDs, payloads, or tokens in logs).
5. **Zero Compiler Warnings & Live Verification**:
   - Compiles cleanly under `-Wall -Wextra -Wformat=2 -O2` with zero warnings.
   - Full test suite in `agent/tests/test_response_dispatcher.c` passes all test vectors (SHA-256, offer parser, replay cache, Ed25519 verification).
   - Verified package build and Debian lifecycle.
   - Deployed and running on live endpoint (`linux-davion-sidarli-reenrolled`); telemetry streaming confirmed.
