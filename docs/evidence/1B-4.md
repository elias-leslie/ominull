Implemented typed action validation, independent SHA-256 payload digest recomputation, strict proof-to-grant binding (tenant, action kind, and target endpoint list), bounded target restrictions, single-use proof nonce replay protection, and length-prefixed canonical Ed25519 grant signing.

## Claims

1. **Independent Digest Recomputation**:
   - Authority independently calculates `sha256(ActionPayload)` and verifies that both requested `ActionDigest` and the browser's signed `Proof.ActionDigest` match the computed payload digest byte-for-byte.
   - Tampered payloads or digests modified in transit are rejected.
2. **Proof Binding Enforcement**:
   - **Cross-Tenant Signing Denied:** `req.Proof.TenantID` must match `req.TenantID`.
   - **Action Kind Matching:** `req.Proof.ActionKind` must match `req.ActionKind`.
3. **Bounded Target Endpoint Verification**:
   - **Unbounded Target Sets Denied:** Proofs with empty target endpoint lists (`len == 0`) are rejected.
   - **Target List Bounds:** Max 1000 target endpoints per proof.
   - **Target Membership:** Requested `req.EndpointID` must be explicitly contained in `req.Proof.TargetEndpoints`. Unauthorized endpoints are rejected.
4. **Crash-Resilient One-Use Proof Nonces**:
   - Nonces checked and recorded in SQLite `used_nonces` table with 10-minute expiration.
   - Replay of an action proof nonce is rejected.
5. **Length-Prefixed Canonical Grant Signing**:
   - Grants encoded via `grant.CanonicalBytes()` (`OMINULL-ENDPOINT-GRANT-V2`), signed with tenant's private Ed25519 key, and verifiable by endpoints against the tenant response public key.
6. **Testing & Deployment**:
   - Verified locally with Go race detector (`go test -v -race ./pkg/responseauth/...`).
   - Verified clean Debian package lifecycle build.
   - Deployed to LXC 150; verified fail-closed behavior and continuous fleet telemetry.
