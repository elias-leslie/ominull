## Production result

The deployed browser loaded 1.8.32 and displayed 17 groups/26 aggregate links.
Labels measured 13.75 px at 1280×900 and 12.06 px at 1024×768, with the inspector hidden
by default at the smaller width. Browser errors were empty. A temporary personal
view created on the real non-secure HTTP console saved 17 positions; reload
restored every coordinate and zoom. Deleting that exact test view left zero views,
matching the count before verification.

Live API verification returned 788 nodes, 817 directed pairs and 12,436 evidence
relations without truncation. A cached response took 0.049307 seconds for 5,703,418
bytes. An endpoint credential received 403 from the workspace route. All six online
endpoints reported driver/package version 1.8.32, native provenance and no isolation.
The two known offline laptops remained outdated; the three retired rows stayed retired.
Final release Go race passed, including server 230.766 s; frontend, worker, vet,
native, package lifecycle, version, managed and secret gates passed.
